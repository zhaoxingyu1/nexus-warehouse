# 接手记忆

## 用户偏好
重视美观、动态效果和讲解价值；不接受静态模型冒充真实运输。货物、路线、装卸应可见。希望参考市场案例，界面之外必须有实际HAP数据闭环。使用现有账号，不要求创建第二个账号。默认继续已授权工作，必要时才询问。

## 必须保持的边界
不提交任何AppKey/Sign/PAT/Cookie。保持生产认证。设备明确标注模拟，智能分析是规则解释，尚未连接语言模型。BI数据范围是当前会话，禁止伪造增长率、利用率历史或全组织指标。业务写入只允许绑定的演示应用。

## 已知问题和下一步
1. 线上登录后全流程复测与实际浏览器长时间回放验证。
2. 投影数据按事件累积；需要归档/保留策略、分页和同版本并发同步防重。
3. 模拟由可见且有写权限的页面推进；关闭页面不继续后台调度。
4. 电量会耗尽，尚无完整自动充电调度；低电量待命不是所有空闲车都能接单。
5. 双向HAP集成、原生关系字段、实体机器人、入库及输送线尚未实现。
6. 路由是有限时域优先预约，不是工业安全认证或所有布局下无死锁的保证。
7. 发布包曾保留旧构建资源，后续应从干净目录构建并核对，不提交历史构建产物。
8. 重置会建立新的模拟会话和初始库存，原始快照保留。不要在生产业务里误用。
